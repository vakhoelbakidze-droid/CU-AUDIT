# CU აუდიტორიების აღჭურვილობის ინვენტარი

ლოკალური ვებ-აპლიკაცია Caucasus University-ის აუდიტორიების ტექნიკის (აქსეს
პოინტი, პროექტორი, სმარტბორდი, კომპიუტერი, მონიტორი, კამერა, დინამიკი)
აღსარიცხად. მუშაობს მხოლოდ თქვენს კომპიუტერზე, ბაზაც იქვეა (SQLite ფაილი).

## გაშვება

1. დარწმუნდით, რომ დაინსტალირებულია Python 3.9+ ვერსია.
2. ტერმინალში გადადით პროექტის საქაღალდეში:
   ```
   cd audit_app
   ```
3. (რეკომენდებულია) შექმენით ვირტუალური გარემო:
   ```
   python3 -m venv venv
   source venv/bin/activate      # Windows-ზე: venv\Scripts\activate
   ```
4. დააინსტალირეთ დამოკიდებულებები:
   ```
   pip install -r requirements.txt
   ```
5. გაუშვით აპლიკაცია:
   ```
   python app.py
   ```
6. ბრაუზერში გახსენით: **http://127.0.0.1:8000**

პირველივე გაშვებისას ავტომატურად შეიქმნება `instance/audit.db` ბაზა და
ჩაიტვირთება თქვენი თავდაპირველი ცხრილის მონაცემები.

## შესაძლებლობები

- **აუდიტორიების სია** — ფილტრი სართულის მიხედვით და თავისუფალი ძებნა
  (კოდით, მოდელით, ინვენტარის ნომრით).
- **დამატება / რედაქტირება / წაშლა** — სრული CRUD ყველა აუდიტორიაზე.
- **ცვლილებების ისტორია** — თითოეულ აუდიტორიას აქვს ცალკე ისტორიის ჟურნალი
  (ვინ, როდის და რა შეცვალა), ასევე არსებობს გლობალური ისტორიის გვერდი.
- **სტატისტიკა** — რამდენ აუდიტორიას აკლია აქსეს პოინტი/პროექტორი.

## მონაცემთა ბაზის შენახვა

ბაზა ინახება ფაილში `instance/audit.db`. თუ გინდათ ბაზის სარეზერვო ასლის
აღება, უბრალოდ დააკოპირეთ ეს ფაილი. თუ გინდათ ბაზის თავიდან შექმნა (ცარიელი
ან თავდაპირველი მონაცემებით), წაშალეთ `instance/audit.db` და ხელახლა გაუშვით
`python app.py`.
